
# ceil(x/d) 轉 整數除法 ，要是正整數才可
x = q * d + r

x:被除數
q:商數
r：餘數
d:除數
0 <= r < d
ex. 12 / 3 = 4 ... 0 => 12 = 4 * 3 + 0

分兩種情況
r = 0 
- x 可整除
- ceil(x/d) = q
- (x + d -1) / d = (q*d + d -1) d
- 整數除法結果還是q (q個d + 0個d[d-1無法被d整除])

r > 0
- ceil(x/d) = q + 1
- (x + d -1) / d = (q*d + r + d -1 ) / d
- 因為r >= 1，所以 r + d - 1 >= d
- 整數除法結果變成 q + 1

# 整數技巧公式
預設 a >= 0 , b > 0
go的整數除法會直接捨去小數

常用公式

  - floor(a / b)

  a / b

  - ceil(a / b)

  (a + b - 1) / b

  - ceil(x / 3)

  (x + 2) / 3

  - 判斷是否整除

  a%b == 0

  - 判斷奇數

  a%2 == 1

  - 判斷偶數

  a%2 == 0

  - 取中間值，避免 overflow 的寫法

  mid := left + (right-left)/2

  - 向下對齊到 b 的倍數
    例如 17 對齊到 5 的倍數變 15

  (a / b) * b

  - 向上對齊到 b 的倍數
    例如 17 對齊到 5 的倍數變 20

  ((a + b - 1) / b) * b

  - 交換兩數

  a, b = b, a

  - 取最小值

  if a < b { ans = a } else { ans = b }

  - 取最大值

  if a > b { ans = a } else { ans = b }

  - 絕對值

  if x < 0 { x = -x }

  - 快速判斷 2 的次方
    1, 2, 4, 8, 16...

  x > 0 && (x&(x-1)) == 0

  - 取最低位的 1

  lowbit := x & -x

  你這題最重要的是這兩個

  - 無條件進位除法：

  (a + b - 1) / b

  - 所以：

  ceil(x / 3) == (x + 2) / 3

  型別 best practice

  - 能全程用 int 就全程用 int
  - 只有答案可能爆掉時，累加器用 int64
  - 避免 math.Ceil(float64(...)) 這種寫法，通常整數公式比較乾淨
